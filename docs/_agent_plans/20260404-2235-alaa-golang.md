# Alaa Golang Skill Authoring

## Goal

Create `skills/sohrab/alaa-golang` as a routing-first Go skill that:

- targets the current officially supported Go release policy rather than inventing a fake Go LTS model
- merges the requested MCP Market guidance on concurrency discipline, Uber-style Go, and Fiber project structure without contradictions
- routes cleanly to the already-installed public Go skills and selected Sohrab skills by skill name instead of filesystem path

## Assumptions

- `skills/sohrab/alaa-golang` already exists as an empty directory and can be populated in place
- the user wants one top-level skill to invoke explicitly, with deeper skill routing handled inside that skill
- the installed Go skills and Sohrab skills are already publicly available, so `alaa-golang` should reference them by name only

## Constraints

- keep `SKILL.md` lean, routing-first, and in English
- put dense detail and long routing tables in `references/`
- use official Go, Fiber, and Uber sources when version-sensitive or technically normative details matter
- preserve the existing repository structure and avoid unrelated edits
