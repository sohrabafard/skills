# Official-first source map

Use this map before generating version-sensitive Azure Pipelines content. Microsoft Learn and Azure DevOps task references outrank examples, blogs, issue threads, Stack Overflow, and other community material.

## Primary sources

- Azure Pipelines docs home: https://learn.microsoft.com/en-us/azure/devops/pipelines/?view=azure-devops
- YAML schema reference: https://learn.microsoft.com/en-us/azure/devops/pipelines/yaml-schema/?view=azure-pipelines
- Task reference: https://learn.microsoft.com/en-us/azure/devops/pipelines/tasks/reference/?view=azure-pipelines
- Expressions: https://learn.microsoft.com/en-us/azure/devops/pipelines/process/expressions?view=azure-devops
- Variables: https://learn.microsoft.com/en-us/azure/devops/pipelines/process/variables?view=azure-devops
- Templates: https://learn.microsoft.com/en-us/azure/devops/pipelines/process/templates?view=azure-devops
- Pipeline security: https://learn.microsoft.com/en-us/azure/devops/pipelines/security/overview?view=azure-devops
- Hosted agents: https://learn.microsoft.com/en-us/azure/devops/pipelines/agents/hosted?view=azure-devops
- Service connections: https://learn.microsoft.com/en-us/azure/devops/pipelines/library/service-endpoints?view=azure-devops

## Freshness triggers

Fetch current Microsoft docs when the task mentions `latest`, `current`, task major versions, hosted image changes, security/permissions, service connections, environments, deployment jobs, expressions, templates, or a task input not present in local references.

## Troubleshooting-only sources

Use Stack Overflow, GitHub issues, forums, and community blogs only for troubleshooting symptoms. Confirm YAML shape, task inputs, security behavior, and hosted-agent claims against Microsoft sources.
