# Official-first source map

Use this map before generating version-sensitive Loki or Alloy configuration. Grafana Loki and Grafana Alloy docs outrank examples, blogs, issue threads, Stack Overflow, and other community material.

## Primary sources

- Loki docs home: https://grafana.com/docs/loki/latest/
- Loki configuration reference: https://grafana.com/docs/loki/latest/configure/
- Loki configuration best practices: https://grafana.com/docs/loki/latest/configure/bp-configure/
- Loki Helm install: https://grafana.com/docs/loki/latest/setup/install/helm/
- Loki Helm chart reference: https://grafana.com/docs/loki/latest/setup/install/helm/reference/
- Loki storage: https://grafana.com/docs/loki/latest/configure/storage/
- Loki operations: https://grafana.com/docs/loki/latest/operations/
- Loki release notes: https://grafana.com/docs/loki/latest/release-notes/
- Grafana Alloy docs: https://grafana.com/docs/alloy/latest/

## Freshness triggers

Fetch current Grafana docs when the task mentions `latest`, Loki version numbers, schema versions, Promtail migration, Alloy components, Helm values, storage backend behavior, multi-tenancy, ruler config, TLS/security, or deprecated config keys.

## Troubleshooting-only sources

Use Stack Overflow, GitHub issues, forum posts, and community blogs only to troubleshoot observed failures. Confirm config syntax, Helm values, storage behavior, and security guidance against Grafana docs.
