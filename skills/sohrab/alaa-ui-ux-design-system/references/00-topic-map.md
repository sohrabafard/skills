# Topic Map

Start here when you know the task area but not yet the exact reference file.

## Choose by task shape

- Need a design direction for a new product, site, or redesign; a design brief; or persisted design decisions:
  - Open `10-design-workflow.md`
- Need design tokens, semantic color roles, theming, dark mode, or spacing/radius/shadow/z-index scales, or how tokens map into Tailwind, Bootstrap, or Quasar:
  - Open `20-design-tokens-and-theming.md`
- Need font pairing, type scale, font loading, Farsi/RTL typography, palette construction, or contrast decisions:
  - Open `30-typography-and-color.md`
- Need to pick or evaluate a visual style (minimalism, glassmorphism, brutalism, bento, aurora, ...) or keep effects coherent with a style:
  - Open `40-styles-and-visual-language.md`
- Need layout rules, breakpoints, page-type layout defaults, landing-page section order, or CTA strategy:
  - Open `50-layout-landing-and-ia.md`
- Need component states, form and feedback design, navigation patterns, empty/loading/error states, or chart design:
  - Open `60-components-states-and-ux.md`
- Need modern CSS design features (container queries, `:has()`, View Transitions, scroll-driven animations, `@starting-style`, popover, anchor positioning) or animation/motion guidance:
  - Open `70-motion-and-modern-css.md`
- Need icons, brand assets, image handling, favicons, OG images, or illustration direction:
  - Open `80-icons-assets-and-imagery.md`
- Need the blocking gates, a design review, or the pre-delivery checklist:
  - Open `90-quality-gates-and-review.md`

## Also load rules

- Any new palette, theme, or dark-mode task:
  - Also load `20-design-tokens-and-theming.md`
- Any style-selection task:
  - Also load `40-styles-and-visual-language.md`
- Any animation, transition, or motion task:
  - Also load `70-motion-and-modern-css.md`
- Any icon or image task:
  - Also load `80-icons-assets-and-imagery.md`
- Any task that ends in shipped UI:
  - Also load `90-quality-gates-and-review.md`
- Any task needing Vue/Quasar implementation or SSR safety:
  - Pair with `$alaa-frontend-developer`
