Read this before using a language feature, a standard-library API, or a toolchain behaviour you have not confirmed the
repository supports.

Before applying version-sensitive guidance in this file, first read [Release status and changes](./70-modern-go-baseline/10-release-status-and-changes.md#verified-releases-and-consumer-applicability) for the verified release and consumer applicability, and [Directive, language, and toolchain](./70-modern-go-baseline/20-directive-language-and-toolchain.md#read-the-directive-before-you-write-the-feature) for the consumer directive.
