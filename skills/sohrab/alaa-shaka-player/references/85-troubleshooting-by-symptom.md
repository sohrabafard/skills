# Troubleshooting by symptom

Find the symptom. Each entry names the mechanism, then routes to the reference that owns it.
Where a Shaka error code exists for the symptom, it is given.
## The player never appears, or crashes on the server
When diagnosing server rendering or player startup, read [Loading and startup symptoms](./85-troubleshooting-by-symptom/10-loading-and-startup.md) for loading and startup symptoms.

## Playback fails to start
When diagnosing manifest, network, or initial playback failures, read [Loading and startup symptoms](./85-troubleshooting-by-symptom/10-loading-and-startup.md) for loading and startup symptoms.

## Playback starts, then breaks
