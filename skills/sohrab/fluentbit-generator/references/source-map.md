## Freshness triggers

Fetch current official docs when the task mentions `latest`, Fluent Bit version numbers, plugin parameters, OpenTelemetry output behavior, Kubernetes metadata behavior, multiline parsing, buffering/storage limits, TLS/security, or deprecations.

## Troubleshooting-only sources

Use Stack Overflow, GitHub issues, forums, and community blogs only to troubleshoot observed failures. Confirm plugin syntax, security behavior, and compatibility claims against Fluent Bit docs.
