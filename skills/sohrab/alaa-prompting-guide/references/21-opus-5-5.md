## Prompting and calibration

Start effort comparisons at the documented default; do not inherit an older generation's pin. Increase effort only after context, tooling and specification problems
are excluded and quality still falls short. Higher effort can add long turns and token cost;
vendor benchmarks cannot establish a gain for this pack.

Current default effort is medium. The official launch's headline benchmarks mostly use max, with Terminal-Bench at xhigh; those measurements do not prescribe max or xhigh for every coding lane. All low/medium/high/xhigh/max levels are supported, subject to actual host controls. Keep workload selection separate from benchmark settings.

Give the desired outcome, complete task context, scope, authority, acceptance criteria and
stop conditions. The official advice to remove generic "think carefully" reminders is chat-specific; do not generalize it into a ban on task-specific agentic reasoning or required checks. Keep
required retrieval, focused tests and independent acceptance gates; use the authority test
in `references/80-subagent-authoring.md` before removing verification language. Define
response length, file length and progress cadence separately from reasoning effort.

For delegation wording, read `references/06-invocation-and-composition.md`; explicit
independent scopes and host permissions still govern what may run.

## API migration boundary

Thinking is always adaptive on this model. Existing API clients must check the migration
guide for unsupported disabled/manual thinking, forced tool choice and assistant prefill,
and preserve returned thinking blocks in tool loops. Recount output budgets before carrying
old limits forward. API history, caching and thinking controls are not automatically
Claude Code settings; read `references/41-claude-code-runtime-features.md` for that surface.
