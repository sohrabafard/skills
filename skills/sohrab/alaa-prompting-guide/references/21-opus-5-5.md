# Claude Opus 5.5

Use this file for current Opus prompting.

## Effort

- The default is `medium`, in Claude Code too (model-config, 14 November 2026). `low`, `medium`, `high`, `xhigh` and `max` are supported, subject to the host's controls.
- Start at the documented default, never at an older generation's pin. Before you raise it, read `references/50-effort-and-thinking.md`. Higher effort can add long turns and token cost.
- The launch benchmarks mostly use `max`, with Terminal-Bench at `xhigh`. They prescribe neither level for a coding lane.

## Prompting

- The official advice to remove generic "think carefully" reminders is chat-specific. Keep task-specific agentic reasoning, required retrieval and required checks.
- Before you remove verification language, apply the authority test in `references/80-subagent-authoring.md`.
- Effort controls no response length, file length or progress cadence. To set one, read `references/50-effort-and-thinking.md`.
- For unattended work, keep an observable completion checklist and harness evidence. Neither narration nor hidden thinking proves that the work is done.
- For delegation wording, read `references/06-invocation-and-composition.md`.

## API migration boundary

Thinking is always adaptive. An existing API client must:

- check the migration guide for unsupported disabled or manual thinking, forced tool choice and assistant prefill;
- preserve returned thinking blocks in tool loops;
- recount output budgets before it carries an old limit forward.

API history, caching and thinking controls are not Claude Code settings; for that surface read `references/41-claude-code-runtime-features.md`.
