# Official-first source map

Use this map before generating version-sensitive Terragrunt content. Terragrunt docs, Terraform/OpenTofu docs, provider docs, and module registry docs outrank examples, blogs, issue threads, Stack Overflow, and other community material.

## Primary sources

- Terragrunt docs home: https://docs.terragrunt.com/
- Terragrunt CLI: https://docs.terragrunt.com/reference/cli/
- Terragrunt configuration blocks: https://docs.terragrunt.com/reference/hcl/blocks/
- Terragrunt attributes: https://docs.terragrunt.com/reference/hcl/attributes/
- Terragrunt built-in functions: https://docs.terragrunt.com/reference/built-in-functions/
- Terragrunt Stacks: https://docs.terragrunt.com/features/stacks/
- Terraform docs: https://developer.hashicorp.com/terraform/docs
- OpenTofu docs: https://opentofu.org/docs/
- Terraform Registry modules/providers: https://registry.terraform.io/

## Freshness triggers

Fetch current official docs when the task mentions `latest`, Terragrunt version numbers, CLI redesign behavior, Stacks, engine selection, OpenTofu/Terraform versions, provider or module versions, remote state changes, or deprecated commands.

## Troubleshooting-only sources

Use Stack Overflow, GitHub issues, discussions, and community blogs only to troubleshoot symptoms. Confirm Terragrunt HCL, CLI behavior, stack semantics, and security guidance against Terragrunt and Terraform/OpenTofu docs.
