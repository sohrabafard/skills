# Official-first source map

Use this map before validating version-sensitive Fluent Bit content. Fluent Bit official docs and plugin docs outrank examples, blogs, issue threads, Stack Overflow, and other community material.

## Freshness triggers

Fetch current official docs when validation depends on Fluent Bit versions, plugin parameter names, deprecated options, OpenTelemetry/Loki/HTTP output behavior, parser semantics, storage/backpressure behavior, TLS/security, or config syntax changes.

## Troubleshooting-only sources

Use Stack Overflow, GitHub issues, forums, and community blogs only to troubleshoot observed failures. Confirm findings and fixes against Fluent Bit docs.
