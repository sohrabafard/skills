# Skill Boundaries

## alaa-workflow

Owns long-running execution, phase prompts, repo-local plans, continuation state, validation evidence, subagent orchestration, and handoff safety.

## alaa-low-noise

Owns bounded terminal and output discipline, avoiding raw dumps and noisy logs.

## Basic Memory

Owns cross-session recall, contract maps, lesson recall, project indexes, decision pointers, and concise handoff pointers.
