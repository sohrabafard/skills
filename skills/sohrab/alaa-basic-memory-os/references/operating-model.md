# Operating Model

```text
Repository docs and source code are the source of truth.
Basic Memory is the agent-queryable map, contract index, lesson layer, decision layer, and continuity layer.
Skills define agent behavior.
Obsidian is the human editing and navigation surface.
raw/processed is the self-improvement evidence warehouse.
```

## Vaults

- `D:/Sohrab/Project/agent-memory` — Basic Memory vault, curated runtime knowledge, git-tracked.
- `D:/Sohrab/Project/docs` — human Obsidian vault, personal prompts and sticky notes.
- `D:/Sohrab/Project/skills/skills/sohrab` — skill source of truth.
- `D:/Sohrab/Project/raw/processed` — Prompt 1/2 evidence warehouse.

## Store in Basic Memory

- architecture maps
- service ownership
- contract cards
- operations/SOC rules
- durable lessons
- repeated work patterns
- project indexes and current state summaries
- concise handoff pointers

## Do not store

- raw sessions
- raw logs
- full source files
- full docs
- full Postman collections
- secrets/credentials/tokens/cookies/private keys
- personal sticky notes
- private prompt drafts
- draft skill contents
- installed skills
- active `alaa-workflow` phase checklists
