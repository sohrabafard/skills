# Official-first source map

Use this map before generating version-sensitive LogQL content. Grafana Loki docs outrank examples, blogs, issue threads, Stack Overflow, and other community material.

## Freshness triggers

Fetch current Grafana docs when the task mentions `latest`, Loki version numbers, new LogQL functions/operators, pattern filters, query acceleration, recording/alerting behavior, label guidance, limits, or syntax rejected by the user's Loki runtime.

## Troubleshooting-only sources

Use Stack Overflow, GitHub issues, forum posts, and community blogs only to troubleshoot observed query/runtime failures. Confirm syntax and operational guidance against Grafana Loki docs.
