# Official-first source map

Use this map before generating version-sensitive Jenkins pipeline content. Jenkins docs and plugin documentation outrank examples, blogs, issue threads, Stack Overflow, and other community material.

## Primary sources

- Jenkins Pipeline book: https://www.jenkins.io/doc/book/pipeline/
- Pipeline syntax reference: https://www.jenkins.io/doc/book/pipeline/syntax/
- Pipeline steps reference: https://www.jenkins.io/doc/pipeline/steps/
- Shared Libraries: https://www.jenkins.io/doc/book/pipeline/shared-libraries/
- Credentials handling: https://www.jenkins.io/doc/book/using/using-credentials/
- Jenkins security: https://www.jenkins.io/doc/book/security/
- Plugin site: https://plugins.jenkins.io/
- LTS upgrade guides: https://www.jenkins.io/doc/upgrade-guide/

## Freshness triggers

Fetch current Jenkins or plugin docs when the task mentions `latest`, LTS upgrades, plugin versions, deprecated steps, credentials/security behavior, Kubernetes/Docker agents, declarative syntax changes, or a step not covered in local references.

## Troubleshooting-only sources

Use Stack Overflow, Jenkins issue threads, mailing lists, and community blogs only to troubleshoot symptoms. Confirm pipeline syntax, step parameters, plugin compatibility, and security behavior against Jenkins or plugin docs.
