# Stack fast paths

These are evidence fast paths, not project instruction ownership.

## Laravel

Use Laravel Boost for installed-package documentation and authorized application context. Use CodeGraph for broad source flow and likely impact, Serena for exact PHP semantics and edits, the contract owner for machine-readable APIs, and repository-native Laravel gates for proof.

## Go

Use CodeGraph for package, handler, consumer, interface-flow, and impact questions. Use Serena for exact definitions, implementations, references, diagnostics, rename, and semantic edits. Use Go commands and repository gates for proof.

## Vue and Quasar

Use CodeGraph for page, route, component, composable, store, API-client, and static integration flow. Use Serena with `vue` for exact Vue and TypeScript semantics; do not add a duplicate TypeScript language when the Vue server supplies its companion server. Use browser/runtime evidence for runtime UI questions and repository-native frontend gates for proof.
