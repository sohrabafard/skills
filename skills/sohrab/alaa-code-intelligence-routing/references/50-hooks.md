# Hook policy boundary

This skill owns only the interaction policy between evidence tools: a CodeGraph-indexed repository should not use Serena's raw-read reminder as a competing discovery governor, because that reminder cannot treat CodeGraph evidence as progress.

Exact hook events, configuration locations, matchers, trust behavior, lifecycle support, and client-specific command shapes belong to `/alaa-prompting-guide` in Claude Code or `$alaa-prompting-guide` in Codex. Read its target-runtime feature reference before creating or changing hooks. Keep project bindings limited to the chosen policy; do not copy runtime documentation into them.

Passive instrumentation may observe routing, but it must not alter permissions, tool output, or the routing decision being measured.
