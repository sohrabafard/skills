## Design and alternatives

Protect source precedence, authorized persistence, recall deadlines, non-reset retries, single adapter,
workflow state ownership, mirrored runtime behavior and current proof distinctions. Reject adapter-owned
policy, dual routers, page-miss absence, local automatic commits and hook captures: each violates those
existing owners/invariants. Keep setup reachable conditionally rather than erase it. Body growth gains the
new capability-inquiry contract; loaded-path savings need later measurements, not a word-count promise.
Rollback is local file restoration; no migration, external effect, installation or committed data occurred.
