# Semantic acceptance cases

These are independent-review cases derived from the user's requirements, not live model evaluations. Reviewers judge source decisions and trace each verdict to the final owning contract. Source facts are in prompting-guide references/90-model-selection.md.

| Case | Expected source behavior | Rejected behavior |
|---|---|---|
| Tiny reversible single edit | Direct work without orchestrator activation overhead | Full role pipeline merely because skill named |
| Finalized bounded feature, no preference | Balanced table cell; Sol medium, matching available role | Inherit lead/high planning effort |
| Same feature, explicit lower cost | Table Sol low plus bounded-role fit | Pretend supported API alone proves fit |
| Reproduced local bug, Balanced | Luna medium bug admission and regression evidence | Force expensive role merely for semantic edit |
| Same bug, user requests High | Priority quality -> Luna high | Treat High as Astra or all effort-high globally |
| Debug/update, quality | Table Sol xhigh if lane fit and role available | Convert quality to literal Sol high |
| Material consequential failure documented | Quality priority with consequence and acceptance rationale | Generic production-is-important blanket escalation |
| Missing context, unavailable tool, unclear intent | Resolve evidence/tool/spec owner before capacity diagnosis | Upgrade model to hide the missing fact |
| Balanced polished-app lane with actual demanding judgment | Source Astra medium admission with lane match and cheaper/decomposition assessment | Force whole app's every child lane to Astra |
| Coupled migration with quality priority | Source Astra xhigh if actual lane matches; retain migration/security gates | Label every file edit migration and inherit goal-wide tier |
| Claude ordinary bounded judgment | Sonnet medium/high according to owned policy | Opus merely because one local choice remains |
| Claude highest-capability claim on long task | Distinguish capability matrix from selector; preserve Fable admission | Every long plan automatically gets Fable |
| New source profile absent in current runtime | Explicit availability limit; no silent substitute or install | Claim repository wrapper was activated |
| Plan finished, worker allocation | One batch records each remaining task's source row, priority, profile, reason, availability | Reopen the entire plan/model search before every dispatch |
| Independent ready lanes under available host slots | Dispatch together within observed resources and contracts | Fixed two-writer ceiling or one agent per trivial checkbox |
| Disjoint files but shared generator/fixture/port | Serialize conflict or isolate with explicit integration barrier | Assume filename disjointness proves independence |
| Compaction/interrupted completed lane | Reconcile plan/checkpoint/diff and attributable unchanged evidence | Replay writes/checks because new agent joined |
| Changed tested input/environment/observer missing | Run affected/missing proof and record invalidation | Cite stale or author-only acceptance |
| Aggregate covers exact children | Run aggregate once; cite covered children with observer/input match | Count/run wrapper and child as distinct proof |
| Sensitive mechanical edit | Economical admitted writer; triggered specialist and independent acceptance retained | Skip gates because model or edit is cheap |

No case proves latency, token reduction, reliability rate or serving identity. Calibration remains unrun.
