## Required proof

- Retired active Sonnet pin, stale projection, disabled-thinking claim or unsupported CLI minimum: canonical Claude policy checker and its negative fixtures. Current versus historical prose additionally needs instruction review.
- Fabricated evaluation success, missing run, uncontrolled observed identity, forbidden action, absent independent review, silent fallback and below-minimum CLI: Claude evaluation checker/self-test. Synthetic fixture evidence strings are not real evidence files. Current corpus remains unrun.
- Lost focused checks/independent gates or invented watchdog timing: both orchestrator agent-contract checkers/self-tests and independent instruction review.
- Agent metadata/grants: owning pack/grant validators and Codex renderer check. Any required rendering mutation belongs to writer before freeze.
- All changed docs/assets: source-to-wording review for stable versus preview, consumer applicability, preserved historical measurements, source honesty, security/authority, examples, ownership and broken links.
- Frontmatter/index/references/lifecycle: four native root checkers named in the plan; whitespace and documentation links/eligible size grades.
- Workflow/coverage: workflow validator plus exact 69-ID comparison to current SKILL.md inventory, evidence paths, status and phase checkboxes.
- Each domain skill's documented validator; self-test when its checker code changed. Do not add consumer integration tests without a consumer change.

## Command owners

Run root scripts from repository root with `python -B`. Model policy/evaluation commands run from prompting-guide as its SKILL.md specifies; orchestrator scripts resolve their own paths. Exact executed commands, cwd, exits and tool versions belong in verifier evidence. Check help before using documentation checker scope/grade flags; do not invent flags.

Freeze candidate before independent verification. Capture HEAD and a sorted path/content SHA-256 manifest including untracked source files, excluding only this task's mutable evidence artifacts and identifying that exclusion. Reviewers use the same source snapshot. Cite valid unchanged focused checks with their original evidence/snapshot instead of repeating them for ceremony; independent integrated checks must cover the combined changed scope. Reopen only gates affected by actual fixes.

## Limits

Schema/source checks are static proof. Fixture execution establishes only checker logic. Neither proves live model availability, identity, quality, latency/cost, runtime behavior, private consumer integration or production performance. No live model calibration or service rollout is required for this local skill-source update; report them unrun. Reader-completion evidence is a prerequisite, not a substitute for independent review.
