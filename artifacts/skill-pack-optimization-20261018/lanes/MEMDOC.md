## Invariants and design

- Selected adapter remains the only operation surface; no memory write, migration,
  setup, bank change, publication, installation or configuration effect occurs.
- Neutral metadata retains provenance, date, status, confidence and vocabulary.
  A Hindsight note does not require a vault path, permalink, YAML or local checker.
- Existing file-vault notes and stable identities remain compatible. Serialization
  relocation changes instructions only, not data. Rollback is a scoped text revert.
- Recall outage stays fail-open; writes, drift records, unknown outcomes and retry
  reconciliation retain existing owner rules. No new concurrency mechanism is added.
- No command list or skill activation supplies escalation authority.
- Documentation ownership follows actual language scope; document language does not
  follow chat language. Runtime spawning mechanics have one capability owner.

- Hindsight selected: retain all neutral semantic metadata without inventing
  frontmatter, a permalink, a file destination or metadata-query support.
- File vault selected: stable permalink, tags, source/date fields and publication
  paths survive, including curated timestamps and write readback.
- Necessary listed gate with no sandbox failure: the list provides no blanket
  unsandboxed authorization. Failed required gate still follows actual approval.
- PHP source docblock: never route it to the frontend-only annotation pass.
- Existing Persian document with an English chat: preserve its language; no new
  translated companion follows automatically.
- Mirror origin missing plus a local defect: exit 2 is no pass; local finding remains.
