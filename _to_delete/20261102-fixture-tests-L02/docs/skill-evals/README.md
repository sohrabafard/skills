# Sohrab Skill Evals

This directory contains repository-local eval assets for the `skills/sohrab` pack.

Contents:
- `manifests/`: one manifest per skill with trigger, sibling-confusion, and hard-negative cases
- `datasets/`: JSONL files ready to upload into OpenAI Datasets
- `manual-review-checklist.md`: reviewer checklist for routing quality and domain safety
- `dashboard-datasets.md`: how to use the local datasets with Datasets, graders, and Prompt Optimizer
- `graders/skill-routing-rubric.md`: shared rubric for manual or dashboard graders
