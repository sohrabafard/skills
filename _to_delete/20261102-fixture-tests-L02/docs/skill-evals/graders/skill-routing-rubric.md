# Skill Routing Rubric

Score each dataset row on these properties:

1. Correct skill activation.
2. Suppression of over-triggering on unrelated prompts.
3. Correct companion-skill selection when the task crosses boundaries.
4. Concise top-level routing instead of loading unnecessary bulk text.
5. Domain-safe advice that stays inside the owning skill.
6. Correct reference branch selection when a specific file or section should be loaded next.
