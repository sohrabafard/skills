# نمونه درخواست شروع

«برای این فیچر نقش delivery lead را بگیر. ابتدا قواعد پروژه و مسیر فعلی کد را بخوان.
از پک آلاء فقط نقش‌های لازم را بار کن. برای بخش‌های مستقل، حداکثر سه زیرایجنت
بساز؛ مالکیت فایل‌ها را پیش از ویرایش مشخص کن. اجرای تست سنگین همزمان فقط یکی
باشد. معیار پذیرش و غیرهدف‌ها را از درخواست استخراج کن، اصلاحات را پیاده کن،
سپس بازبینی مستقل و بررسی یکپارچه انجام بده. نتیجه را با شواهد تست تحویل بده.»

برای بررسی محدود:
«با alaa_scout مسیر این خطا را پیدا کن. بعد alaa_debugger با شواهد علت را مشخص کند.
فعلاً اجازه تغییر کد ندارند. نتیجه باید reproducer، فایل/نماد و پیشنهاد تست باشد.»

برای Terra:
«با alaa_ui_fixer فاصله‌گذاری و overflow همین کامپوننت را با این مرجع اصلاح کن.
فقط این فایل‌ها مجازند. viewport و حالت فرم ثابت باشد؛ رفتار keyboard و RTL را
هم بررسی کن. اگر علت در state یا API بود، قبل از توسعه دامنه به lead تحویل بده.»
