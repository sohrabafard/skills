# Independent review
Provide the reviewer the task contract and exact base/current diff. Give enough
surrounding code to trace behavior. Do not lead with the author's conclusion.
For high-risk changes, add a security/data/algorithm specialist with a distinct lens.
Each finding requires a trigger, evidence, impact and confidence. Deduplicate by
root cause; do not manufacture a quota. Reconcile disagreement through executable
evidence or authoritative contracts. Re-review changed portions after fixes.
