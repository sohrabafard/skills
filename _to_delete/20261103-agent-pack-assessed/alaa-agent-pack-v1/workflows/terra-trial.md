# Terra adoption experiment
Select scoped, verifiable tasks in Python, PHP, JavaScript/TypeScript and visual UI.
Run Terra and Sol on identical clean starting states, input context, tools and effort.
Include Luna as a cost baseline and Astra as a quality reference when budget allows.
Keep an untuned holdout set. Separate first-attempt success from success after repair.
Record total task cost including failed attempts, reviewer correction and tool costs;
measure wall time and human attention. Promote Terra only for task families where
its quality bar is met. Do not extrapolate CSS success to tenant isolation or SQL.
